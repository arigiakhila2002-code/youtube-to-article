# 🎥 YouTube to Insightful Article & PDF
A Python automation project that downloads YouTube audio, transcribes it with Whisper AI, converts it into an article, and exports a professional PDF.

Convert any YouTube video into a readable article and professional PDF using Python, AI transcription, and automation tools.

---

## 🚀 Features

✅ Download audio from YouTube videos
✅ Convert speech to text using Whisper AI
✅ Generate clean article-style content
✅ Export polished PDF notes
✅ Works great with tutorials, lectures, and courses

---

## 🛠 Tech Stack

* Python
* yt-dlp
* OpenAI Whisper
* ReportLab
* python-dotenv

## ⚙️ Installation

```bash
pip install yt-dlp openai-whisper reportlab python-dotenv
```

---

## ▶️ How to Run

```bash
python main.py
```

Then paste a YouTube video URL when prompted.

Example:

```plaintext
https://youtu.be/example
```
